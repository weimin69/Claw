# 一页速览｜面试前 10 分钟

> 详细版见 `01-项目答辩卡.md`。这张只保留最小可回答集。

## 30 秒介绍

用 Rust 写的终端 SWE Agent。用户给自然语言任务，它在授权工作区内探索仓库、读写文件、执行命令、跑测试，根据结果继续下一轮，最后汇总改动与命令。核心是“模型决策 + 工具执行 + 可验证的编码闭环”，聊天是次要能力。

## 架构一句话

```text
cli.rs → commands/claw.rs → AgentSession/AgentState → run_turn_loop
                                                   ├── AgentModel → ChatEndpoint → OpenAI-compatible API
                                                   └── ToolExecutor → Workspace + 文件/命令工具
最终：AgentEvent / ToolEffect → CLI 报告 + session.rs 存档
```

- CLI 负责组装与展示。
- `AgentSession` 管完整历史和工作上下文；`AgentState` 管单轮预算。
- `run_turn_loop` 管“模型—工具—模型”循环。
- `AgentModel` 和 `ToolExecutor` 是两个可替换边界。

## 三个问题卡（各 30 秒版）

### 1. 429/503 导致会话中断

- **根因**：传输错误没分类；重试放错层。
- **方案**：`ChatEndpoint` 统一请求；只重试 408/429/5xx/网络/超时；3 次尝试，1s/2s 退避，`Retry-After` 上限 30s；4xx 和非法 JSON 不重试；`RetryNotice` 交给 CLI。
- **取舍/验证**：无 jitter；超时重试可能重复计费；Wiremock 覆盖 503→200、耗尽、400 不重试。

### 2. 工具失败要不要终止 Agent

- **根因**：可恢复失败和致命失败混在一个错误通道。
- **方案**：`ToolOutput::error` 是可恢复错误，作为 tool message 回填模型；执行器外层 `Err` 才是致命；工具预算按整批检查。
- **取舍/验证**：模型可能反复试错，需要预算兜底；测试覆盖无效参数、混合成功/失败、致命错误。

### 3. 命令超时、输出洪水、子进程残留

- **根因**：没有进程组、输出背压和超时控制。
- **方案**：程序名+参数数组、workspace cwd、60s 超时、并发排空 stdout/stderr、每流 32 KiB、Unix 进程组 + RAII 清理、移除 API key 环境变量。
- **取舍/验证**：截断会丢信息；后代可能脱离进程组；不是 OS 沙箱。

## 十个追问（一句话答案）

1. **为什么 Trait 抽象？** 解耦 Runtime 与 Provider/工具，便于 fake model 做确定性测试；只保留两个必要边界。
2. **为什么工具串行？** 保证消息顺序和错误语义简单；读工具以后可并行，写工具需要事务/冲突处理。
3. **怎么防无限循环？** 迭代预算 + 工具次数预算 + 上下文预算；整批超限不执行；默认不设预算，无人值守应显式配置。
4. **工具失败为什么不退出？** 文件不存在/命令非零退出是模型可观察并修正的事实；只有执行器不可继续才终止。
5. **路径越界怎么防？** 启动 canonicalize 根目录；目标 canonicalize 后必须 `starts_with(root)`；新建文件只解析已存在父目录；边界检查不是沙箱。
6. **重试会重复计费吗？** 会，尤其超时重试；只重试模型请求，不重试工具；没有 idempotency key。
7. **命令超时怎么清理？** Unix 独立进程组 + RAII guard + `kill_on_drop`；后代脱离进程组仍可能逃逸。
8. **存档怎么不写坏？** 同目录临时文件 + `sync_all` + 原子替换；保存前确认文件未被外部改；加载校验版本/workspace/消息顺序/工具配对。
9. **为什么按字节不是 token？** 可直接从内部 JSON 精确计算，不依赖 tokenizer；缺点是不等于模型真实窗口，没有摘要。
10. **最大限制/重做改什么？** 无 OS 沙箱和逐命令审批、失败轮次关闭会话、无流式/token 预算/trace；优先补审批和失败回滚。

## 不要说的五句话

- “实现了完整沙箱。” → 只有路径边界，没有 OS 隔离。
- “支持所有模型。” → 目前是 OpenAI-compatible API。
- “有 token 预算/自动摘要。” → 目前是字节预算，没有摘要。
- “支持完整 patch/多文件事务。” → 目前是单文件精确替换 + 不覆盖创建。
- “所有代码都是我独立手写的。” → 按实际参与度说。
