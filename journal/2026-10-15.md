# 2026-10-15

## Objective

清理早期 Rust 练习命令，建立聚焦 SWE Agent 的工程基线，并开始理解和实现 OpenAI-compatible `AgentModel` 适配器。

## Changes

- 删除 `hello`、`echo`、`divide`、`sum`、`repeat`、`wait`、`parallel-wait` 和旧 `version` 子命令。
- 删除 `parallel-wait` CLI 集成测试及相关模块注册和命令分发。
- 改用 Clap 原生 `--version`。
- 移除 Tokio 已无用途的 `test-util` feature。
- CLI 当前只保留 `chat`、`fetch` 和 `read-config`。
- 更新 README 的项目定位、当前能力、命令、配置和架构说明；Markdown 代码块与环境变量说明仍需整理。
- 将 `PROJECT_STATUS.md` 从旧学习流水账收敛为当前工程状态，并迁移到仓库根目录。
- 在 `OpenAiCompatibleAgentModel` 中加入第一版 `AgentModel::next_decision()` 实现，复用已有 client、请求构造、status 检查和响应解析逻辑。

## Engineering Decisions

- 练习型命令不再保留在产品 CLI 中；相关历史由 Git 和 journal 保存。
- 继续保留 `chat`、`fetch` 和 `read-config`，后续根据 Agent CLI 成熟度再评估去留。
- 普通单轮 Chat 暂时维持现有入口；Agent 请求通过持有 `reqwest::Client` 的模型适配器复用连接。
- `openai_compatible.rs` 只负责协议与 HTTP 通信，Agent 编排继续由 `agent.rs` 负责。
- 当前仍明确拒绝单轮多个工具调用，不在适配器任务中扩大运行时模型。

## Tests & Verification

- 清理完成后，`cargo fmt --check`、`cargo check` 和完整 `cargo test` 曾通过，共 56 个测试。
- 加入第一版 `AgentModel` 实现后，`cargo check` 通过。
- 加入第一版实现后，`cargo test openai_compatible` 通过，13 个协议测试全部成功。
- 当前 `cargo fmt --check` 失败，原因是新增实现尚未按 rustfmt 格式整理。

## Issues

- `src/openai_compatible.rs` 新增了未使用的 `reqwest::Client` import。

- 新增 HTTP 适配器尚无 Wiremock 测试，现有 13 个测试没有实际调用 `next_decision()`。
- Agent Runtime 仍未接入 CLI。
- README 仍缺少规范代码块和 `AGENT_CLI_LLM_API_KEY` fallback 说明。
- 工作区还有与本次功能无关或来源较早的 `.DS_Store`、`AGENTS.md` 和 `LEARNING_ROADMAP.md` 修改，未对其归属作出假设。
