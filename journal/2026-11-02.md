- `SESSIONS.md`：删除 `add` 工具行。
- `src/openai_compatible.rs`：
  - 新增 `ChatEndpoint`，统一 `next_decision` 与 `send_chat_request` 的请求、超时与重试逻辑。
  - 新增 `RetryPolicy`：默认 3 次尝试、1 s/2 s 确定性退避、上限 30 s；`Retry-After` 只解析整数秒并截断到 30 s。
  - 新增 `RetryNotice` 与 observer：可重试状态为 408、429、500、502、503、504，以及连接失败、超时、请求中断、响应体读取失败；4xx、构建器错误、2xx 非法 JSON 不重试。
  - 重试耗尽后的错误包含尝试次数；非 2xx 错误改为 `agent`/`chat request failed with status ...`。
  - 删除 `build_add_tool()` 及其注册。
- `src/commands/claw.rs`、`src/commands/chat.rs`：注入重试提示回调，向 stderr 输出 `[模型请求] 失败（…），Xs 后重试（第 N/M 次尝试）`。
- `src/tools.rs`：删除 `AddInput`、`execute_add` 与 `"add"` 分发分支，移除不再使用的 `anyhow!` 导入。
- 测试：新增 6 个重试单元测试，`claw` 与 `chat` 各 1 个重试集成测试，新增默认工具集精确断言；`add` 相关单元/集成测试改用 `read_file`；三个用 500 模拟“请求失败”的测试改为 400，保持非可重试语义并避免测试等待。
- `README`：删除 `add` 说明与限制项，补充重试规则，测试总数 215 → 217。

## Engineering Decisions

- 重试属于传输层，放在 `ChatEndpoint` 内；Runtime 与工具层不感知 HTTP 状态码，`AgentModel` 边界不变。
- 只重试无副作用的模型请求；工具执行失败仍作为可恢复工具结果返回模型，不混入重试。
- 退避确定性，不做随机抖动，保证行为可复现；`Retry-After` 只支持整数秒，HTTP-date 回退到退避。
- 展示仍归 CLI：适配器只发出 `RetryNotice`，由命令层打印，避免传输层直接写终端。
- 删除 `add` 后，默认模型工具集固定为 `list_files`、`read_file`、`search_code`，并用完整 schema 断言防止回退。
- 本次未改变失败语义：任何失败轮次仍会关闭会话，保持“失败后不可复用”。

## Issues

- 重试次数与模型超时仍是常量，没有配置项；无随机抖动；`Retry-After` 不支持 HTTP-date；超时重试可能重复计费，文档尚未声明。
- 任意失败仍使交互会话不可复用；一次 401 或重试耗尽会丢失当轮上下文（存档保留上次成功快照）。
- 失败/取消轮次不打印执行统计；已落盘文件与已执行命令不回滚。
- 终端展示仍写在 `commands/claw.rs`，直接依赖 stdout/stderr；TUI 前需抽离为前端无关事件。
- `README` 保持无扩展名，未改名为 `README.md`（按开发者要求）。
- 状态文件原有的“手动跨进程 `--resume` 验收”实际已由 `tests/session_resume.rs` 覆盖，已更正。
- 仍无 CI、LICENSE、真实模型评估集与结构化执行 trace。
