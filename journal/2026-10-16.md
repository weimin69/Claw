# 2026-10-16

## Objective

完成真实 OpenAI-compatible Agent 模型适配器验证，将 Agent Runtime 接入名为 Claw 的 CLI，并增强工具错误处理和多工具调用能力。

## Changes

- 整理 `OpenAiCompatibleAgentModel::next_decision()`，移除未使用 import 并完成格式化。
- 添加 Wiremock 测试，覆盖最终回答、工具调用、认证与请求体、非 2xx 和非法响应。
- 新增 `claw` CLI 命令，支持 prompt、stdin fallback 和 `--max-iterations`。
- 新增 Claw CLI 集成测试，覆盖直接最终回答和模型—工具—模型完整闭环。
- 引入 `ToolOutput`，区分成功结果、可恢复工具错误和致命执行器错误。
- 将无效参数、未知工具和计算溢出作为可恢复错误返回模型。
- 将模型决策和消息历史扩展为支持单轮多个工具调用。
- 增加多工具解析、执行、协议映射、混合成功/错误和空调用列表测试。

## Engineering Decisions

- 用户可见产品命令命名为 `claw`，内部通用运行时继续使用 `agent` 命名。
- 一次模型响应中的多个工具调用保存在同一条 `AssistantToolCalls` 消息中，保持 OpenAI-compatible 协议语义。
- `ToolOutput::error` 表示可恢复工具失败；`ToolExecutor` 返回的外层 `Err` 表示致命执行器失败。
- 多个工具调用当前按模型返回顺序串行执行，暂不引入并发。
- `max_iterations` 限制模型决策轮数，不等同于工具调用总量限制。
